## The name

> **I Divorced Him For Better Wi-Fi**

31 characters — one Wi-Fi network name that lands a joke and implies a
whole story in the few words a passer-by sees in a phone's network list.

## The story it tells

A marriage ended — and the reason was the Wi-Fi. Not infidelity, not
money, not irreconcilable differences: the signal next door was simply
better. In one line you get the character (a spouse who has had enough),
the situation (a marriage measured against a router), and the event (the
divorce, already final). The word "Better" does the heavy lifting: it
implies comparison shopping, a neighbour's network, and a decision made
with a straight face. It twists the familiar "left him for the Wi-Fi"
trope into something new — a divorce, not a fling — and stays far from
the stock Wi-Fi jokes ("FBI Surveillance Van" and friends).

## How to run

```sh
python3 main.py
```

This writes the name to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is not set). The file contains
exactly the 31-character name, UTF-8, no trailing newline.
